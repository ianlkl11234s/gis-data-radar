## 1. Overture Maps 2026 年 9 月版

本週更新：9/23 版本新增台灣三縣市地址來源（發布說明未列名稱）；目前有 2026-09-23.1 修正版。Schema v2 移除 places.categories，改用 taxonomy 或 basic_category。

- 範圍／尺度：全球向量；台日各地覆蓋與定位品質不一致，無統一公尺精度保證
- 更新：每月；另有不定期修補
- 格式／介接：GeoParquet、GeoJSON、PMTiles、STAC。雲端公開讀取；Explorer 無須帳號，可下載視窗範圍 GeoJSON
- 授權：依 theme／來源不同；Places 列 CDLA Permissive 2.0，地址需逐來源核對顯名與條件，不可當成統一授權
- 專案用途：試驗台日 POI 缺口與地址定位覆蓋；先以一縣市／城市裁切，與現有官方設施資料比較
- 整合：整合成本估計中：分類映射、同址去重、權利核對及版本釘選。

注意事項：
- Addresses 仍是 alpha
- 2026-09-23.1 修正 base 和 building_parts GERS ID；補丁發布日期未單獨確認
- schema breaking changes 需處理
- 未抽樣驗證台日實際覆蓋與下載檔

## 2. 115 年土石流與大規模崩塌潛勢

今年資料精選：可補坡地風險底圖，並與現有道路、橋梁、避難及降雨資料套疊。

- 範圍／尺度：台灣列管 1,753 條土石流潛勢溪流及 94 處大規模崩塌潛勢區；線、集水區、影響範圍面，非全台連續風險評分
- 更新：115 年度；不定期更新
- 格式／介接：SHP。官方資料頁提供下載；TWD97，實作前核對 .prj。此複合條目發布日為公告日；兩個子資料集均於 2026-01-13 上架。
- 授權：政府資料開放授權條款第 1 版；可作產品／服務，須顯名
- 專案用途：設施與公告影響範圍套疊；先做單一縣市，驗收後擴全台
- 整合：首選；成本低至中：核對 CRS、轉 WGS84、簡化切 PMTiles，保留年度與風險級別。

注意事項：
- 不是即時災情；未圈選不代表安全
- 頁面未給統一測繪精度
- 土石流影響範圍詮釋資料更新日 2026-02-24；崩塌影響範圍 2026-01-14，故不合併為單一更新日
- 已核對資料頁，未成功驗證 SHP 二進位下載
- 原始資料含保全住戶地址，建議公開圖層不暴露逐戶地址

## 3. NASA FIRMS 衛星熱異常

既有資料精選：為歷史消防火災紀錄增加近即時衛星觀測，兩者需分開命名與呈現。

- 範圍／尺度：全球 VIIRS 375m、MODIS 1km，包含台日；解析度為感測像元，非火場邊界或定位誤差
- 更新：隨衛星過境產出；全球 NRT 一般過境後 3 小時內可用，非每處每 3 小時掃描
- 格式／介接：CSV、SHP、KML、WMS、WFS。bbox CSV API 需免費 MAP_KEY；每次 1–5 天，5,000 transactions／10 分鐘。未申請 key 或測試實際回傳。
- 授權：NASA 官方支持開放使用，須正確引用並遵守免責說明；所讀頁未見限非商用條件
- 專案用途：台日 24–48h 衛星熱異常時間圖層；與森林、AQI 和消防歷史資料比較
- 整合：第二順位；成本低至中：後端快取、去重、信心值與觀測時間、延遲顯示。

注意事項：
- 熱異常可能是工業等固定熱源，不等於火災通報
- 雲遮及過境限制可漏測
- 美加超即時能力不能套用台日
- 近即時資料與後續標準科學產品可能不同

官方來源：
- [解析度、下載格式及時間範圍](https://firms.modaps.eosdis.nasa.gov/active_fire/)
- [全球 NRT 延遲與美加時效差異](https://www.earthdata.nasa.gov/s3fs-public/2023-03/FIRMS_OnePager_2022_Prnt-Web.pdf)
- [bbox API、天數、MAP_KEY 限額](https://firms2.modaps.eosdis.nasa.gov/api/area/)
- [NASA 使用與引用說明](https://forum.earthdata.nasa.gov/viewtopic.php?t=5184)

## 4. JAXA GCOM-C 海表溫度

既有資料精選：與珊瑚、船舶圖層搭配顯示海洋環境。日、半月、月及日夜產品已列入官方 STAC。

- 範圍／尺度：全球約 250m，含台灣、日本及近岸；雲造成缺值
- 更新：日、半月及月產品；未驗證最新影像日期或實際發布延遲
- 格式／介接：COG、GeoTIFF、STAC。Earth API 無須註冊或 key；JS／Python，支援按區域解析度取資料。
- 授權：API 可免費使用；資料授權逐 collection 核對。適用 Research Data Terms 的資料可商用，需註明 API 使用。具體 SST collection 授權仍待核驗。
- 專案用途：台灣海域至琉球、日本海溫背景；與珊瑚及船舶活動套疊
- 整合：成本中：日期、nodata、固定色階、範圍查詢，避免全球 raster 主執行緒解碼。

注意事項：
- collection 外部端點未能開啟，具體授權、最新日期及延遲未驗證
- 不能直接稱為海洋熱浪或珊瑚白化警報
- 須保留雲遮與 nodata，避免插值造成不存在的觀測

官方來源：
- [全球約 250m、雲遮、COG/STAC、API 授權概則](https://data.earth.jaxa.jp/en/)
- [SST 日／半月／月、日夜 collection 存在](https://data.earth.jaxa.jp/stac/cog/v1/catalog.json)
- [免註冊 key、MapLibre 範例與 API 能力](https://data.earth.jaxa.jp/api/javascript/v2.0.1/en/docs/)

## 5. JAXA 日本 10m 土地覆蓋 v25.04

既有資料精選：2025 年 4 月發布，可比較都市、農地、森林、太陽能板、濕地與岩礁／潮間帶；非 2026 新影像。

- 範圍／尺度：日本 2020、2022、2024 三期，約 10m、15 類；WGS84、1°×1° GeoTIFF
- 更新：三期相隔兩年；未確認未來固定發布頻率。發布時間只知 2025-04，故 published_at 留 null。
- 格式／介接：GeoTIFF、COG、STAC。原下載站需註冊；Earth API STAC 已列 HRLULC.v25.04_japan，可評估免 key COG 路線，未驗證實際 collection 回傳。
- 授權：待釐清：Earth-graphy 入口標免費可商用，原始產品頁仍寫商用請先聯絡；須核對具體 collection 條款。
- 專案用途：與 PLATEAU、日本水系及觀光圖層套疊；三期太陽能／濕地／城鄉土地覆蓋比較
- 整合：成本中：先裁切一區、三期 raster tiles、統一分類與授權核驗。

注意事項：
- 入口與原產品商用說明不一致，不能只採較寬鬆標籤
- 分類差異不一定是真實土地變化
- 分類 raster 要 nearest/mode 重採樣，不能連續值插值
- 非台灣土地覆蓋資料

官方來源：
- [2025-04 發布、三期、15 類、10m 與座標格式](https://www.eorc.jaxa.jp/ALOS/en/dataset/lulc/lulc_v2504_e.htm)
- [註冊下載及商用先聯絡的文字](https://www.eorc.jaxa.jp/ALOS/en/dataset/lulc_e.htm)
- [入口標示免費可商用](https://earth.jaxa.jp/en/data/2562/index.html)

## 日期規則

published_at 表示已確認的發布日期；source_updated_at 表示單一明確的來源更新日期；discovered_at 與 last_verified_at 是本次發現及核對日期。未知或只有月份時為 null，不推造完整日期。複合條目的各子資料日期在限制與來源內分別保留。
